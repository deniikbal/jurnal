# Redesign `/dashboard/jadwal` — modern, simple, mobile-first

## Goal
Samakan kualitas visual & responsif halaman Jadwal dengan page yang sudah di-polish (`kelas`, `siswa`, `jurnal`), tanpa mengubah data flow / CRUD.

## Current gaps
- Header masih plain text (page lain pakai gradient hero)
- Stat card polos (`Card` + muted icon), bukan style ring/gradient
- Day tabs & mobile list masih “basic”
- Desktop table kurang polish (hover, header weight, empty state)
- `ScheduleFilter` sudah ada tapi **tidak dipakai** (opsional, tidak dipaksa di redesign ini)

## Approach (UI-only di `app/dashboard/jadwal/page.tsx`)
Reuse pola page `kelas` / `jurnal`. Logic tetap:
- `getSchedulesForCurrentUser` + filter by `day` + sort `jamKe` / `startTime`
- Pagination `PAGE_SIZE = 10`
- `ScheduleCreateDialog` / `ScheduleActions` tetap

### 1. Hero header (gradient)
- Banner indigo/cyan (bedakan dari jurnal teal, kelas blue, siswa emerald)
- Icon + title “Jadwal Pelajaran” + subtitle
- Tombol **Tambah Jadwal** di hero (full-width di mobile, auto di desktop)

### 2. Stat cards (4 kolom → 2 di mobile)
Style seperti `kelas` (`statConfig` + ring/gradient + icon tint + bar tipis):
- Total Jadwal
- Slot hari terpilih
- Mapel
- Kelas

### 3. Day switcher lebih modern
- Sticky/scroll horizontal di mobile (`overflow-x-auto`, no scrollbar jank)
- Chip hari + count badge
- Highlight hari aktif pakai primary/teal
- Opsional kecil: label “Hari ini” jika `day` = weekday sekarang (Sen–Jum)

### 4. List container
Card header:
- Icon + “Jadwal Hari {Day}”
- Count ringkas (`N slot`)
- Create dialog di kanan (desktop); mobile sudah di hero

### 5. Desktop table (`sm+`)
- Border + `shadow-2xs`, header `bg-muted/30`, row hover
- Kolom: Jam · Waktu · Mapel · Kelas · Aksi
- Mapel dengan avatar icon monogram/kode
- Empty state icon + CTA “Tambah jadwal”

### 6. Mobile cards (fokus redesign)
Ganti card datar jadi **timeline-ish** sederhana:
- Left accent bar / jam-ke pill
- Title mapel + kode
- Meta row: waktu mono + kelas
- Actions di footer bordered (touch target tetap dari `ScheduleActions`)
- Spacing `space-y-3`, padding nyaman jempol

### 7. Pagination & empty
- Sama API pagination, polish layout mobile (centered, text ringkas)
- Empty: icon besar + copy + tombol tambah

## Out of scope (kecuali diminta)
- Wire ulang `ScheduleFilter` (mapel/kelas)
- Ubah schema / server actions
- Full calendar week grid
- Ganti komponen dialog create/edit (kecuali class kecil biar selaras)

## Files
| File | Change |
|---|---|
| `app/dashboard/jadwal/page.tsx` | Redesign layout utama |
| `components/schedule-actions.tsx` | Hanya jika perlu touch/spacing minor |
| `components/schedule-create-dialog.tsx` | Tidak diubah (sudah mobile-aware) |

## Color accent
**Indigo** (`from-indigo-600 …`) untuk hero + tint icon list — beda dari modul lain, cocok nuansa “kalender/jadwal”, dan primary global tetap teal.

## Acceptance
- Desktop & mobile rapi, selaras page dashboard lain
- Filter hari + CRUD + pagination tetap jalan
- Tidak break dark mode (pakai token + opacity class yang sudah ada)
